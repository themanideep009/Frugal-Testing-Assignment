## 📌 Executive Summary

Modern software engineering is transitioning from manual deterministic coding to **AI-Native paradigms**. However, LLM code synthesis often introduces false-positive assertion chains, context fragmentation, and security vulnerabilities. This project demonstrates zero-trust automation architectures, stateful cryptographic API testing, pixel-color rendering context polling, and non-generative static verification gates designed to hold autonomous AI models accountable against production-grade edge cases.

### 2. Section A: Practical Anti-AI Engineering & Automation (20 Points)

#### Q1. Dynamic HTML5 Canvas State Drifts & Async Race Interceptions (15 pts)
- **Files:** [`section_a_q1/server.js`](section_a_q1/server.js) | [`section_a_q1/test_q1.js`](section_a_q1/test_q1.js)
- **Features:**
  - **WebSocket Jitter Interception:** Intercepts binary WS packets via CDP route handlers, injecting dynamically scaling Fibonacci delay models ($1000\text{ ms} \times \text{Fibonacci}$) capped at $8000\text{ ms}$.
  - **Pixel Engine Polling:** Anti-AI pixel-color detection executing `requestAnimationFrame` evaluation loops on the Canvas 2D context to identify state transitions from Gray (`#475569`) to Active Green (`RGB(34, 197, 94)`).
  - **Race Injection Macro:** Chained mouse action sequence (Hover $\rightarrow$ Drag 15px $\rightarrow$ Click) executing within **45 ms** (target window: 30ms–100ms) wrapped in a custom circuit-breaker macro.
  - **Server Boundary Assertions:** Validates UI exception handling upon injecting scientific notation float strings (`1e+7`).

#### Q2. Cryptographic Replay Testing & Stateful Nonces (4 pts)
- **Files:** [`section_a_q2/mock_server.js`](section_a_q2/mock_server.js) | [`section_a_q2/test_q2.js`](section_a_q2/test_q2.js)
- **Features:**
  - **Dynamic Sequence Chaining:** POST request initializes transaction, extracting `X-Transaction-ID` and `X-Challenge-Nonce`.
  - **HMAC-SHA512 Authentication:** Generates `X-Frugal-Mac` header dynamically over payload + microsecond timestamp + salt sequence.
  - **Replay Attack Injection:** Resends exact duplicate packet within **3 ms** ($< 150\text{ ms}$ window). Asserts backend correctly drops replay with **HTTP 409 Conflict**.

#### Q3. Sealed Closed-Boundary Shadow DOM & Accessibility CoT Prompt (1 pt)
- **Files:** [`section_a_q3/shadow_dom_piercer.js`](section_a_q3/shadow_dom_piercer.js) | [`section_a_q3/cot_accessibility_prompt.md`](section_a_q3/cot_accessibility_prompt.md)

## 💻 Quick Start & Local Execution

### Prerequisites
- Node.js (v18 or higher)
- npm (Node Package Manager)

### Step 1: Install Dependencies
```bash
npm install
npx playwright install chromium
```

### Step 2: Run Automation Suites

#### Run Q1 (Canvas State Drifts & WebSockets):
```bash
# Terminal 1: Launch WebSocket Mock Server
npm run q1:server

# Terminal 2: Run Automation Test
npm run q1:test
```

#### Run Q2 (HMAC API & Replay Attack):
```bash
# Terminal 1: Launch Express Mock Gateway
npm run q2:server

# Terminal 2: Run Replay Test
npm run q2:test
```

#### Run Q3 (Shadow DOM Traversal Engine):
```bash
npm run q3:test
```
